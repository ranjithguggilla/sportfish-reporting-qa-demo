# Quick Demo Walkthrough (~5 minutes)

Use this order so the story is easy to follow.

1. Go to **Submit Trip**. Click **Load Demo Values**, then create the trip, catch, and tag report (watch the green success text).
2. Switch **Role** to **analyst** in the top bar.
3. Open **Analyst Queue**. Click **Run QA**, then use **Review** (or another action) on one row.
4. Open **Analyst Exports**. Load the QA summary and download CSV or GeoJSON if you want files on disk.
5. Switch **Role** back to **angler**.
6. Open **My Contributions**, click **Load Trip**, and point at the trip ID you just made. You should see KPI cards, map dots, and the timeline.
7. Optional: open **Recapture timeline**, enter a tag code, and read the ordered events.

Tip: If a trip ID already exists, click **Load Demo Values** again to get fresh IDs.
