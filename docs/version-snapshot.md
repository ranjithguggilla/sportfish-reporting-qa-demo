# Current Demo Snapshot

What works today, what is rough, and what could come next.

## Working today

- Submit trip, catch, and tag reports through the browser.
- Run QA checks and see flags in the analyst queue.
- Change flag status (review / escalate / dismiss).
- Download CSV and GeoJSON catch tables (analyst role).
- View QA summary counts as JSON (analyst role).
- Angler view: KPI cards, simple map, timeline, tag history page.

## Rough edges

- Map is a lightweight preview, not a full GIS map.
- “Weather window” is a tiny helper field based on time of day, not live weather.
- Login is simplified to a role switch for the demo.

## Possible next steps

- Photo checks for tag pictures (optional).
- Better maps or extra layers if you move beyond a demo.
- Packaging or automated tests if this becomes a real product.
