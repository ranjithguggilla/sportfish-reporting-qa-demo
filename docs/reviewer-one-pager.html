Reporting and Tagging Intelligence Portal

Demo app · fake data · human review · CSV/GeoJSON exports · GitHub repo name: sportfish-reporting-qa-demo

Problem

  • Outdoor trip reports arrive with missing fields, odd numbers, GPS mistakes, or duplicates.
  • Teams lose time fixing spreadsheets instead of reviewing the stories in the data.
  • Volunteer reporters stay engaged when they can see clear feedback on what they submitted.

Prototype

  • Submit trip, catches, optional tag notes.
  • Automatic checks flag likely issues.
  • Analyst queue for review actions.
  • Downloads (CSV / GeoJSON) plus a QA summary.
  • A simple participant view with totals, map dots, and timelines.

Where this could help

  • Faster intake with fewer broken records.
  • Easier review workflow for small teams.
  • Cleaner handoff files for maps and spreadsheets.
  • Friendlier visibility for volunteer reporters.

Honest wording: this is workflow software. It does not estimate fish abundance or replace expert decisions.
